# 2026-05-10 Changes

2026년 5월 10일에 추가된 주요 작업을 기능 단위로 정리한 문서입니다.

## ESP32-P4 + ESP32-C6 Wi-Fi Remote

- ESP32-P4가 자체 Ethernet 대신 ESP32-C6 보조 칩을 통해 Wi-Fi를 사용하도록 설정했습니다.
- ESP-Hosted SDIO host interface를 활성화했습니다.
- 공유 가능한 기본 설정은 `sdkconfig.defaults`에 정리했습니다.
- 로컬 빌드 산출 설정인 `sdkconfig`와 `sdkconfig.old`는 Wi-Fi SSID/password 같은 환경값을 포함할 수 있어 Git 추적 대상에서 제외했습니다.

## MobileNetV2 Classifier

- 펌웨어용 분류 모델을 MobileNetV2 `0.35-width` 기준으로 정리했습니다.
- `model/model_utils.py`에 `MODEL_WIDTH_MULT = 0.35`를 추가했습니다.
- 학습 체크포인트에 `width_mult`를 저장하도록 변경했습니다.
- ONNX export 단계에서 체크포인트의 `width_mult`가 현재 설정과 다르면 실패하도록 검증을 추가했습니다.
- torchvision 기본 ImageNet pretrained weight는 `width_mult=1.0`에만 호환되므로, 현재 `0.35-width` 설정에서는 랜덤 초기화 학습을 사용합니다.

## Classification SDIO Transfer

- `/classify.jpg` 요청 처리 후 JPEG 이미지와 추론 결과를 ESP-Hosted custom data로 C6에 전송하는 송신 경로를 추가했습니다.
- `main/sdio_frame_protocol.h`에 SDIO frame message ID, magic, version, chunk header 구조체를 정의했습니다.
- `main/sdio_frame_tx.c`에서 JPEG를 여러 chunk로 나누고 각 chunk에 분류 결과 metadata를 붙여 전송합니다.
- `main/simple_video_server_example.c`에서 분류 성공 후 `sdio_frame_tx_send_classification()`을 호출하도록 연결했습니다.
- `main/CMakeLists.txt`에 `sdio_frame_tx.c`와 `esp_hosted` 의존성을 추가했습니다.

## Documentation

## Repository Hygiene

- `sdkconfig`와 `sdkconfig.old`는 보드별 로컬 설정 파일로 보고 Git에서 제거했습니다.
- 재현 가능한 공통 설정은 `sdkconfig.defaults`에 유지합니다.
- 이미 GitHub에 올라간 Wi-Fi 비밀번호는 저장소에서 파일을 제거해도 과거 commit에는 남을 수 있으므로 실제 AP 비밀번호는 변경하는 것이 안전합니다.
